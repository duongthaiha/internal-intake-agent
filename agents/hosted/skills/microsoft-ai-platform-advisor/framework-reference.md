# Framework reference

This compact reference is derived from the Microsoft AI Decision Framework at
commit `5939bfac7f2f80c5ae773042fb089c5ab01fd893`.

## Build-before-buy ladder

1. Use an existing capability.
2. Discover an existing agent, connector, or template.
3. Configure a supported product.
4. Extend a product with approved connectors or actions.
5. Build declaratively or with low code.
6. Build and operate a custom pro-code solution.

## Workload routing

- Microsoft 365 interaction and knowledge work: start with Microsoft 365
  Copilot.
- Low-code conversational or event-driven workflow: evaluate Copilot Studio.
- Microsoft 365-centric pro-code extension: evaluate Microsoft 365 Agents SDK.
- Azure-centric custom application: evaluate Microsoft Foundry and Microsoft
  Agent Framework.
- Integration-led autonomous workflow: evaluate Azure Logic Apps agentic
  workflows.
- Managed headless agent hosting: evaluate Foundry Agent Service.
- Analytics-centric data workload: evaluate Microsoft Fabric.

## Risk

- Individual productivity: keep actions bounded and transparent.
- Internal expert knowledge: require grounding, citations, access control, and
  specialist review.
- Business-critical or external action-taking: require explicit human
  oversight, auditability, failure controls, and formal security, privacy, and
  responsible-AI review.
